# 公用模块（抽取层）

两包顶层同名列表见 [`../docs/shared-modules-manifest.md`](../docs/shared-modules-manifest.md)。

当前仓库 **未复制** `soucre/*/*.xpp` 内文件，避免与 IDE 工作副本重复。实际抽取时建议：

1. 选定主版本包（例如版本号较新的 24XD 或你指定的主分支）。
2. 在 XXTouch 中对比另一包同名 `.xxt` 的差异后，再覆盖或合并。
3. 合并后分别用 24SC、24XD 各执行一次冒烟（评价最小路径 + 下单最小路径）。

若后续在此目录下建立 **统一副本文档或脚本**，仅用于团队约定，不替代 `.xpp` 包内真实文件。
