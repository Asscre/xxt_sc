# 24XD（下单）开发计划（函数级任务与验证）

本文档对应源码树 [`soucre/24XD/24XD.xpp`](../soucre/24XD/24XD.xpp)。入口由 [`Info.lua`](../soucre/24XD/24XD.xpp/Info.lua) 指定为 **`main.xxt`**，界面为 **`interface.xuic`**（另有 **`xui-sub.xuic`**）。

业务脚本为 **`.xxt` 编译字节码**，须在 **XXTouch IDE** 中对照实际调用名；下列链路按 **文件名语义** 归纳。

---

## 1. 假定调用链（待 IDE 校准）

```text
main.xxt
  → 下单主函数.xxt（下单总入口）
       → 下单_APP下单.xxt（App 内下单主路径）
       → 下单相关函数.xxt / 下单相关截图函数.xxt（页面跳转、截图找图）
       → 下单_公共界面.xxt、界面处理主函数.xxt
       → 下单_设置地址.xxt、设置地址相关函数.xxt（地址与配送）
       → 下单_领优惠券.xxt（可选分支）
       → 下单_返回到首页.xxt（重置或异常恢复）
       → 下单_扫码付款.xxt（扫码支付分支）
       → 代付相关函数.xxt（代付/亲友付等）
  → 下载图片函数.xxt（商品图或素材）
  → TouchIOS.xxt（触控/坐标相关封装，名称表明与原生触控有关）
  → 备用代码.xxt（降级或未启用分支，需在 IDE 内确认是否可达）
  → 与 24SC 共用的：复登、滑块轨迹、激活、pjy、商品标题读取等
```

| 序号 | 模块文件 | 任务 | 验收 |

## 3. 合规与安全（强制）

- **不在仓库或脚本中硬编码支付密码、完整 cookie、支付验证码**；密钥按你方安全策略存放。
- **下单金额、商品 ID** 建议配置化，默认使用测试商品。
- **扫码付款 / 代付**：明确是否自动化到最后一步；涉及资金与人脸核验的流程须符合法律与平台规则，仅限授权环境验证。

---

## 4. 验证步骤（建议顺序）

1. **最小闭环**：低价测试商品，完成「提交订单」或约定止步点（与业务确认）。
2. **异常**：缺货、限购、风控弹窗、网络超时（对照截图函数与 `res/`）。
3. **双包回归**：修改 [`docs/shared-modules-manifest.md`](shared-modules-manifest.md) 中任一共享文件后，SC 与 XD 各跑一次冒烟。
