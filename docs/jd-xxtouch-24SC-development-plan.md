# 24SC（评价 / 收菜）开发计划（函数级任务与验证）

本文档对应源码树 [`soucre/24SC/24SC.xpp`](../soucre/24SC/24SC.xpp)。入口由 [`Info.lua`](../soucre/24SC/24SC.xpp/Info.lua) 指定为 **`main.xxt`**，界面为 **`interface.xuic`**（另有 **`xui-sub.xuic`**）。

业务脚本为 **`.xxt` 编译字节码**，须在 **XXTouch IDE** 中打开同名模块对照调用关系；下列「调用链」按 **文件名语义与京东业务** 归纳，你在 IDE 中应将条目替换为实际 **全局函数名 / 标签**。

---

## 1. 假定调用链（待 IDE 校准）

```text
main.xxt
  → 脚本配置界面.xxt / 界面处理主函数.xxt（参数、弹窗与界面分支）
  → 确认收货或评价主函数.xxt（收菜 + 评价总控）
       → 收菜相关函数.xxt
       → 收菜_确认收货.xxt / 收菜_确认收货返回.xxt
       → 收菜_评价.xxt / 收菜_评价返回.xxt
       → 评价函数.xxt（星级、文案、晒图/跳过等）
       → 确认收货函数.xxt（与确认收货页交互）
  → 算法滑动.xxt / 滑块轨迹.xxt / 旋转轨迹.xxt（验证码或人机校验场景）
  → 与 XD 共用的：下单_公共界面.xxt、下单_JD复登.xxt、下单_设置地址.xxt、设置地址主程序.xxt、设置地址相关函数.xxt、代付相关函数.xxt 等（若 SC 流程中会下单或唤起收银台）
```

**图像模板**：大量逻辑依赖 [`res/`](../soucre/24SC/24SC.xpp/res) 下 PNG（如「写评价」「提交」「评价中心」等），改版时需同步更新模板与匹配阈值。

## 2. 函数级任务清单（按模块）

下列每项在 IDE 内完成后打勾；「验收」为自动化或人工最小闭环。

| 序号 | 模块文件 | 任务 | 验收 |
|------|-----------|------|------|
| SC-1 | `main.xxt` | 理清启动顺序：是否先读配置、是否循环任务、异常退出码 | 冷启动一次日志完整 |
| SC-2 | `界面处理主函数.xxt` | 列出所有分支入口（返回首页、关闭弹窗、网络失败重试） | 表格或注释导出 |
| SC-3 | `脚本配置界面.xxt` + `interface.xuic` | 列出界面绑定变量：账号、间隔、开关项 | 与运行行为一致 |
| SC-4 | `确认收货或评价主函数.xxt` | 状态机：待收货→确认收货→待评价→提交→结束 | 流程图 + 失败分支 |
| SC-5 | `收菜相关函数.xxt` | 订单列表进入、滚动、定位订单项 | 截图/日志核对 |
| SC-6 | `收菜_确认收货*.xxt` | 确认收货按钮与返回路径 | 单次闭环 |
| SC-7 | `收菜_评价*.xxt` | 进入评价页、匿名、话题、晒图分支 | 单次闭环 |
| SC-8 | `评价函数.xxt` | 星级、文字输入、话题选择、直接提交节点 | 与 `res/` 模板一致 |
| SC-9 | `收菜_删除订单.xxt` / `收菜_永久删除.xxt` | 触发条件与二次确认 | 仅在需求启用时测 |
| SC-10 | `确认收货函数.xxt` | 与 SC-6 差异（若有封装层） | 不重复点击 |
| SC-11 | `算法滑动.xxt` 等 | 何种界面触发滑块、超时与重试 | 异常界面录屏 |
| SC-12 | `处理上次出现的界面.xxt` | 崩溃恢复与上次界面栈 | 杀进程恢复测 |
| SC-13 | `下单_*` / `设置地址*` / `代付相关函数.xxt` | 若评价链路会经过下单或支付页，只对用到的分支做对照 | 按需 |
| SC-14 | `pjy.xxt`、`复登相关函数.xxt`、`下单_JD复登.xxt` | 登录态失效时的复登 | 踢下线场景 |
| SC-15 | `nLog.xxt`、`text_replacement.xxt` | 日志路径、敏感信息脱敏 | 自查日志 |

## 3. 验证步骤（建议顺序）

1. **环境**：固定京东 App 版本、设备分辨率、XXTouch 与系统权限（相册、网络等）。
2. **配置**：仅用测试小号；界面参数最小集跑通一单「确认收货 + 评价」。
3. **异常**：断网、`评价中心_网络请求失败`、活动弹窗（对照 `res/` 命名）。
4. **合规**：禁止违反平台规则的自动化用途；测试仅限自有订单与授权账号。
5. **回归**：京东小版本升级后重跑 SC-4～SC-8 核心路径。
